# Roadmap

## Milestone 0 — Combat prototype (current)
- [ ] Stat + damage engine (types, conversion, increased/more, crit, resists, ailments)
- [ ] Player: move, dodge, 5 Rites
- [ ] 3 enemy types + a boss
- [ ] Juice: hit-stop, shake, damage numbers, particles, glow
- [ ] Loot: rarities, affixes, pickup, inventory, equip, tooltips
- [ ] XP and levels
- [ ] Generated zone ending in a boss arena

## Milestone 1 — Vertical slice
- Ember Constellation (passive tree), first ~60 nodes
- Support gems (Rite modifiers): more projectiles, chain, added fire, etc.
- ~15 Rites, one fully realized class fantasy
- Sound pass, real art pass for player + 3 enemies
- Save/load, stash

## Milestone 2 — Co-op
- Host-authoritative multiplayer (Godot high-level multiplayer / ENet), 1–4 players
- Shared world, instanced loot

## Milestone 3+
- More zones/acts, uniques, crafting, endgame loop
